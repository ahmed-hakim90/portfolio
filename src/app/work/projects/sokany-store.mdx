## Overview

**Sokany Store** is the production Arabic **RTL** storefront for **Sokany Elmaghraby**, built as part of my Frontend Engineer role. It uses **Next.js**, **TypeScript**, **Tailwind CSS**, and the **WooCommerce REST API** so the company keeps WooCommerce as commerce backend while shipping a faster, mobile-first shopping experience.

## Problem

Standard WooCommerce storefronts can be slow, visually generic, and difficult to tune for a modern mobile-first customer experience. Sokany needed a storefront that could keep WooCommerce as the commerce backend while giving the frontend more control over performance, UX, and product presentation.

## Solution

I built a headless storefront layer that communicates with WooCommerce through REST APIs and focuses on the customer-facing experience:

- Responsive UI in Next.js
- WooCommerce REST integration with resilient error handling (including unstable responses such as 502s)
- Performance work on loading and perceived speed
- Arabic RTL mobile UX
- PWA-ready product experience
- Modern storefront presentation including richer product viewing patterns

## Architecture

WooCommerce remains the system of record for catalog and commerce data, while the Next.js frontend handles routing, page rendering, responsive UI, and API-facing commerce flows. This split makes it easier to optimize the storefront without being blocked by theme constraints.

## Impact

The project shows a practical e-commerce architecture: keep WooCommerce for operations and catalog management, but build a faster, more branded shopping interface on top of it.
