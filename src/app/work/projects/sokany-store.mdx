## Overview

A **Next.js** storefront talking directly to **WooCommerce** over the REST API — optimized for performance and clearer UX than a typical WooCommerce theme.

## What I shipped

- Responsive UI in Next.js
- WooCommerce REST integration with resilient error handling (including unstable responses such as 502s)
- Performance work on loading and perceived speed
