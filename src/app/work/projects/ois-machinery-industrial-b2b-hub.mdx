## Overview

**OIS Machinery** (OIS Institution) is a B2B industrial web presence for machinery supply, auxiliary parts, and turnkey project services. The site targets manufacturers and procurement teams with a performance-focused catalog, company credibility content, and low-friction contact paths.

## Problem

The original web presence looked dated and did not communicate the quality of the company, its machinery catalog, or its turnkey industrial capabilities. Navigation was basic, visual hierarchy was weak, and the site did not provide a strong path from discovery to inquiry.

## Solution

I rebuilt the experience as a modern industrial B2B hub with clearer positioning, premium machinery presentation, structured service pages, dynamic catalog routes, and direct lead-capture channels through WhatsApp and email.

## Features

- **Home** — hero, value props, industry tags, animated stats, featured machines and parts, partner strip, CTA
- **About** — company profile, milestones (2011 / 2014 / today), strengths
- **Services** — comprehensive services, turnkey delivery (feasibility → commissioning → support)
- **Machines** — categorized catalog with **dynamic detail pages** (`/machines/:slug`)
- **Auxiliary Parts** — parts grid by category (hydraulics, electrical, conveying, etc.)
- **Contact** — form and direct channels
- **Floating WhatsApp** — `wa.me` deep links with optional pre-filled message
- **SEO** — per-route meta, Open Graph (`/og.jpg`), canonical URLs

## Tech

React 19, TanStack Router / TanStack Start, Vite 7, Tailwind CSS 4, Radix UI + shadcn-style components, Framer Motion, Zod + React Hook Form, Cloudflare Workers (Wrangler).

## Impact

The project repositioned OIS from a basic company website into a stronger industrial product presence: clearer B2B messaging, better machine discovery, higher credibility, and faster inquiry paths for procurement and manufacturing teams.
