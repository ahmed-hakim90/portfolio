## Overview

Structured **Next.js API routes** sit between the frontend and **WooCommerce**, normalizing responses and reducing timeouts and flaky client-side calls.

The preview above is from **Store OMS** ([workflow-management-ecommerce.vercel.app](https://workflow-management-ecommerce.vercel.app/)) — the landing highlights **WooCommerce** among integrations; the API work fed the same operational reality (orders, storefront webhooks, stable payloads).

## Problems tackled

- Unstable API responses and intermittent failures
- Timeouts under load
- Hard-to-debug data flow from theme-only Woo setups

## Approach

- Centralized fetch logic with consistent error handling
- Predictable JSON for the UI layer
- Clear separation between storefront components and WooCommerce specifics
