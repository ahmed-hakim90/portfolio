## Overview

**Cairo Quarantine Administration** web portal surfaces official guidance for travelers and citizens: **service paths** (international travel, Hajj & Umrah, citizen services), **vaccine information**, **office locations**, linked **PDFs**, and a **WhatsApp** entry point for support.

The interface is **RTL-first** for Arabic, with **English** and **Chinese** locales via static routing.

Next.js (App Router), locale-aware layouts, responsive mobile-first UI.
