## Overview

[HAKIMO CV](https://hakimo-cv.vercel.app/) is the public face of this codebase (`ahmed-portfolio`), separate from earlier learning demos like **Personal Site**. The live site uses an Arabic **RTL** layout: a marketing landing (features ticker, hero, metrics, testimonials) and a browser-style **preview** of a portfolio page with profile, projects, and theme controls.

## Stack

**TypeScript**, **MDX** for content, modern frontend tooling, deployed on **Vercel**.
