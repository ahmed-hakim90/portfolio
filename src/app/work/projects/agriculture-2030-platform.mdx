## Overview

**منصة وزارة الزراعة الرقمية 2030** (zra3a-2030) منصة GovTech عربية RTL لعرض مشروعات ومبادرات وزارة الزراعة واستصلاح الأراضي وربطها برؤية مصر 2030. تجمع قائمة مشروعات موحّدة، صفحات تفصيلية، بحث وتصفية، ولوحة مؤشرات في تجربة متجاوبة تخدم المواطن والإعلام والجهات المعنية.

جزء من منظومة [رؤية مصر 2030 — منصة التحول الرقمي](/work/egypt-vision-2030-digital-platform).

## المشكلة في الوضع الحالي

- صفحة المشروعات والمبادرات الرسمية تعتمد هيكلاً تقليدياً يصعّب اكتشاف المحتوى.
- غياب بحث وتصفية مركزيين للوصول السريع لمشروع محدد.
- لا توجد صفحة تفاصيل موحّدة لكل مشروع بمعايير عرض حديثة.
- تجربة الجوال غير محسّنة لاستعراض عدد كبير من المبادرات.
- عدم وجود لوحة مؤشرات تربط إنجازات الوزارة برؤية مصر 2030 بشكل بارز.
- صعوبة تحديث وإضافة مشروعات جديدة دون إعادة هيكلة الصفحات يدوياً.

## الحل

منصة ويب حديثة تعرض مشروعات الزراعة في بطاقات قابلة للبحث والتصفية، مع صفحة تفاصيل لكل مشروع ولوحة مؤشرات وربط بصري برؤية 2030 — جاهزة لاستيراد بيانات المشروعات آلياً.

## المميزات

- جاهزية لاستيراد مشروعات الزراعة آلياً (scraper-ready)
- قائمة مشروعات ومبادرات موحّدة
- صفحات تفاصيل لكل مشروع
- بحث وتصفية وتصنيفات
- واجهة عربية GovTech RTL
- تصميم mobile-first
- لوحة مؤشرات وإحصائيات
- توافق مع رؤية مصر 2030

## Tech

React 19, TypeScript, TanStack Router / Start, Tailwind CSS, shadcn/ui, واجهة RTL عربية GovTech.
